This project is an end-to-end Machine Learning based Customer Demand Forecasting System developed using Python. The system predicts future product demand using historical sales data and time series feature engineering techniques.

The project covers:
- Data preprocessing
- Feature engineering
- Machine Learning model training
- Forecast evaluation
- Interactive deployment with Streamlit

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit

## Features
- Demand prediction using ML
- Time series feature generation
- Interactive forecasting dashboard
- Business-oriented analytics workflow

## Use Cases
- Inventory planning
- Sales forecasting
- Supply chain optimization
- Predictive analytics
